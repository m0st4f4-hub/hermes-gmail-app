Hermes Gmail

Hermes Gmail is a personal desktop productivity assistant. It connects a locally installed agent ("Hermes") to the owner's own Google account so the agent can, at the owner's direction, read and organize mail, draft replies for the owner's review, maintain the owner's calendar and documents, and keep the owner's own contact and spreadsheet data in sync on the owner's machines.

The application is used only by its owner on the owner's own devices. It does not operate a service for third parties, does not sell data, and does not run a public website beyond this page.
